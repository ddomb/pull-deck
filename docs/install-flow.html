The app starts listening

A hollow icon appears in the menu bar. It opens its socket, scans every Chromium-family browser on the Mac, finds the extension nowhere yet, and says so.

Load the extension

Click Reveal Folder and Open Extensions in the panel. Turn on Developer mode, choose Load unpacked, pick the folder. It registers under the pinned id straight away — there is nothing to copy down.

↳
automatic · ≤5s

The app installs the bridge

The five-second scan notices the extension and writes the native messaging host manifest into that browser — pointing at its own bundle, allowing only the pinned id.

↳
automatic · ≤60s

The extension connects

Its retry finds the manifest, Chrome spawns the relay, the relay attaches to the socket. The icon fills in and shows a count. Impatient? Retry now in the extension's Settings does it immediately.

3
you

Paste a GitHub token

In the extension popup — deliberately not in the app. The token never crosses the bridge, so it lives in exactly one place. Both surfaces fill in at once.

Why the order doesn't matter

The arrows only ever leave the browser. A native app cannot open a connection into an extension — Chrome spawns the relay itself and kills it with the port. So the app listens, and the browser reaches out. That inversion is why the app treats “nothing attached” as an ordinary state rather than an error.

When it doesn't work

SymptomCauseWhat happens
“Reload the extension” Loaded before the id was pinned; Chromium keeps whatever id it had at load time Named explicitly. Press reload on its card — self-corrects
“Not running” Bridge installed, app closed Extension backs off up to 30 min. Open the app, hit Retry now
You moved the app Manifest path went stale Rewritten on next launch from its own bundle path
You moved the repo Used to change the extension id Nothing. The id is pinned by the manifest key
You removed the extension Manifest left behind Cleaned up on the next scan
Browser not detected Something unusual about its profile layout Run --diagnose; it lists every directory it considered
