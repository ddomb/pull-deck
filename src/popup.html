Pull Deck

    Connect GitHub

    Pull Deck reads your open pull requests and puts them in one tab group. It needs a personal access token to do that.

    Stored in this browser profile only, and sent nowhere except api.github.com. It is not encrypted, so revoke it on GitHub if this profile is shared.

    Scopes it needs
    repo read:org

    Create a classic token with these scopes. Fine-grained tokens are scoped per repository, so they tend to miss pull requests in orgs they were not granted.
